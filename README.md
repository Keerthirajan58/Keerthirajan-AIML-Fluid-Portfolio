# Keerthirajan Senthilkumar · Portfolio

**Live site:** https://keerthirajan-aiml-fluid-portfolio.vercel.app

The personal portfolio of an AI/ML and software engineer.

## How I built it

- **Framework:** Next.js (App Router) with TypeScript, statically generated and deployed on Vercel.
- **Design:** an original "Clear Air" visual language. Solid cards float over a soft light field that shifts as you scroll, and the site has light and dark themes. The styling is hand-written in Tailwind CSS v4 and modern CSS, including scroll-driven animations.
- **Interaction:** the intro line types itself out like a model generating text. It also has glass lens hover effects, an animated experience timeline and filterable project work. Lenis and Motion are used sparingly.
- **Content:** a typed, validated content model, so new projects, roles and credentials are data rather than new code.
- **Quality:** unit, accessibility and real-browser tests (Vitest, Testing Library, Playwright), security headers, and Lighthouse checks for performance, accessibility and SEO.
