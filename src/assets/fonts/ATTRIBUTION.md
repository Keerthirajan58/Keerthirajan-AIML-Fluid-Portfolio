# Self-hosted fonts

- Inter, The Inter Project Authors: https://github.com/rsms/inter
- Unbounded, NaN / Google Fonts contributors: https://github.com/google/fonts/tree/main/ofl/unbounded

Both use SIL Open Font License 1.1. Next serves these locally: Unbounded for headings (and the OG image, via `Unbounded-ExtraBold.ttf`), Inter for body text. Inter/Unbounded Latin subsets were recovered from the asset-only stash; no failed application code was restored.
